## 一、怎么打开（30 秒）

1. 解压本压缩包；
2. **双击 `index.html`** 即可（推荐 Chrome / Edge 最新版，无需联网、无需服务器、无需安装任何依赖）；
3. 首页 → 点「▶ 进入三维机房漫游」体验 3D；点「设备台账检索」「AutoCAD 实训」进入对应模块。

> 如果学校要求用网址访问，把整个文件夹放到任意静态服务器（Nginx / Apache / IIS / GitHub Pages）根目录即可，`index.html` 就是入口。
> 本地也可以在该目录执行 `python -m http.server 8080`，浏览器打开 `http://localhost:8080`。
> **公网部署（Cloudflare Pages / Workers / GitHub Pages）遇到报错？看 [DEPLOY.md](DEPLOY.md)** —— 里面已经配好 `package.json` 与 `wrangler.jsonc`，零构建直传即可。

**三维机房操作**：左键拖动环视 · 右键拖动平移 · 滚轮缩放 · 点击设备看档案 · 「漫游」模式用 `WASD` 走动 · 「巡检」模式自动巡场。

## 四、换成你们实验室的真实台账（3 步）

> 评审很看重「设备名称、型号、数量与实验室台账一致」，建议把下面几处改成真实数据。

1. **改数据**：编辑 `assets/js/data.js`
   - `LAB.lab`：实验室名称、房号、面积、工位数、开放时间、联系方式、简介、功能定位；
   - `LAB.devices`：按台账逐条改 `no / name / model / qty / unit / cat / spec / purpose / principle / ops / safety`；
   - `LAB.safety`、`LAB.procedure`、`LAB.experiment`：按本实验室制度与真实实训项目替换。
   保存后刷新页面，卡片、台账表格、检索、统计数字会自动同步。
2. **对一下三维热点**：`assets/js/scene3d.js` 里的 `hotspotDefs`（15 个热点）用 `dev` 字段指向设备编号。
   如果设备增减，把对应热点的 `dev` 改成新编号；不存在的设备直接删掉那一行即可（其余不受影响）。
3. **（可选）换图标与照片**：`assets/js/glyphs.js` 里的 SVG 可替换成自己画的图标；若要放实拍照片，把图片放到 `assets/img/`，在 `data.js` 中把 `glyph` 换成图片路径并在 `devices.html` 里把 `<svg>` 换成 `<img>`。

**实训项目参数**：`LAB.experiment.params / paramsMeta` 里改 `W H d D dx dy` 的默认值与滑块范围，任务卡、参考图与评分标准会同步变化。

## 五、迷你 CAD 绘图板用法（实训页）

| 命令 | 快捷键 | 说明 |
|---|---|---|
| LINE 直线 | `L` | 点第一点、点第二点连续画线，`Esc` 结束 |
| RECTANG 矩形 | `REC` | 点两个对角点 |
| CIRCLE 圆 | `C` | 点圆心、再点半径点 |
| DIM 线性标注 | `DIM` | 点两个特征点，自动生成带数值的尺寸 |
| ERASE 删除 | `E` | 点选图元删除 |
| UNDO 撤销 | `U` | 逐步回退 |

辅助：`F8` 正交（仅作用于直线）、`F3` 对象捕捉（端点/圆心/象限点）、`F7` 参考图显隐、滚轮缩放、右键拖动平移。
画完点「提交并评分」，按**外形尺寸 25 + 安装孔 30 + 中心孔 20 + 中心线 10 + 尺寸标注 15** 自动打分并给出评级与改进建议。

## 六、技术说明

- **零构建、零依赖、零联网**：全部为原生 HTML/CSS/JS（ES5 语法，兼容老机房浏览器），Three.js r152 已本地内置，不会出现断网白屏；
- **数据驱动**：页面结构由 `data.js` 生成，换实验室只改数据，不动页面；
- **图形全部程序化**：设备图标为手写 SVG，动画为 CSS keyframes，无外部图片与视频，压缩包体积小、加载快；
- **性能**：三维场景采用 InstancedMesh 合并 40 套桌椅（约 320 个实例），1024 阴影贴图，弱显卡也能 30fps 以上；鲁棒性：窗口尺寸变化自动重排，触摸/鼠标统一用 Pointer Events。
